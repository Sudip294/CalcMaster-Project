# CalcMaster

[![View Live Site](https://img.shields.io/badge/View-LiveSite-blueviolet?style=flat&logo=vercel&logoColor=white)](https://calc-master-project.vercel.app)

CalcMaster is a sleek, modern, and fully responsive web application offering a powerful calculator, BMI index, and age counting tools. Designed for students, professionals, and everyday users, CalcMaster combines intuitive functionality with elegant design to deliver precise calculations and insightful health metrics.

---

## 🚀 Features

- **🧮 Calculator:** Perform basic arithmetic operations with a user-friendly interface, including calculation history and keyboard support.
- **⚖️ BMI Index:** Calculate your Body Mass Index with detailed results, visual meter, and history tracking.
- **⏳ Age Count:** Compute your exact age in years, months, days, hours, minutes, and seconds with a personalized greeting and history.
- **🌗 Dark/Light Mode:** Toggle between dark and light themes with smooth transitions and theme persistence.
- **📱 Responsive Design:** Optimized for desktops, tablets, and mobile devices.
- **🎵 Audio Feedback:** Button click sounds enhance user interaction.
- **📜 Calculation History:** View and manage your recent calculations for all tools.
- **🔧 Progressive Web App (PWA):** Offline support and installable on supported devices.

---

## 🛠️ Technologies Used

- **HTML5 & CSS3** with custom animations and responsive layouts
- **JavaScript (ES6+)** for dynamic functionality and state management
- **Bootstrap 5** for base styling and responsive grid system
- **Font Awesome** for crisp, scalable icons
- **Service Worker** for PWA capabilities

## ⚙️ Project Setup

To run CalcMaster locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/Sudip294/CalcMaster-Project.git
   ```
2. Open the `html-file/index.html` or other HTML files in your preferred web browser.
3. No additional setup or dependencies are required as this is a static web application.
